## 🚀 Project Experience

### 🔹 할래말래 | 공공체육센터 예약 & 운동 메이트 커뮤니티 플랫폼
👉 **GitHub Repository 바로가기**  
🔗 **https://github.com/MUNJI-KANG/Best_Choice_Project**

**Overview**
- 국민체육진흥공단 주최  
  *2025 국민체육진흥공단 공공데이터 활용 경진대회* 출품작
- 공공체육센터 예약 기능과  
  함께 운동할 사람을 찾는 커뮤니티 기능을 결합한 웹 플랫폼

**Problem**
- 공공체육센터 데이터가 분산되어 있고 구조가 복잡해  
  사용자가 원하는 시설을 찾고 예약하기 어려움
- 개인 운동 중심의 서비스로는  
  운동 지속성과 참여도가 낮다는 문제 인식

**Role**
- 팀장
- 백엔드 및 프론트엔드 개발 전반 담당

**Approach**
- 국민체육진흥공단 공공데이터 수집 및 API 구조 분석
- 서비스 흐름에 맞게 데이터 구조 재설계
- 체육센터 예약 기능 및 커뮤니티 기능 설계
- DB 모델링 및 CRUD 구현
- Ajax 기반 비동기 처리로 사용자 경험 개선
- Django REST API 설계 및 구현
- AWS EC2 환경에 웹 서비스 배포

**Result / Insight**
> 공공데이터는 그대로 사용하는 것보다  
> 서비스 맥락에 맞게 재구성할 때 실제 사용성과 확장성이 확보된다.
